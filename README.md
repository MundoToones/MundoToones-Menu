# Mundo Tunes — Menú Digital

Menú digital de **Comidas Rápidas Mundo Tunes**, desplegado como sitio estático en GitHub Pages.

## 🚀 Ver menú en vivo

👉 [Ver Menú](https://TU_USUARIO.github.io/toones-food/)

## 📁 Estructura

```
Toones food/
├── index.html          # Página principal del menú
├── assets/
│   └── svg/
│       ├── logo.svg            # Logo del negocio
│       ├── card-frame.svg      # Marco decorativo para cards
│       ├── category-title.svg  # Título de categoría
│       └── divider.svg         # Divisor entre secciones
└── README.md
```

## 🛠 Despliegue en GitHub Pages

1. Sube este repositorio a GitHub
2. Ve a **Settings → Pages**
3. En _Source_, selecciona **Deploy from a branch**
4. Selecciona la rama `main` y carpeta `/ (root)`
5. Guarda — en unos minutos el menú estará en vivo

## ✏️ Actualizar precios o productos

Edita directamente el archivo `index.html`. Cada producto está en un `<article class="card">` dentro de su sección.
